# Contributing / Contribuir

English: use Windows and Node.js 22+. Run `npm ci`, `npm test`, then `npm start`. Isolate data with `PULSEPAD_DATA`. `npm run dist` builds Windows x64 packages. Do not commit songs, recordings, private libraries, secrets or generated binaries. Spanish translation keys and English values are in `src/locales/en.json`; update both languages and test. Include meaningful checks for playback, persistence or routing changes and explain their limits.

Español: usa Windows y Node.js 22+. Ejecuta `npm ci`, `npm test` y `npm start`. Aísla los datos con `PULSEPAD_DATA`. `npm run dist` genera paquetes x64. No subas música, grabaciones, bibliotecas privadas, secretos ni binarios generados. Actualiza los dos idiomas en `src/locales/en.json` y prueba la interfaz. Comprueba los cambios de reproducción, persistencia o audio y explica sus límites.
